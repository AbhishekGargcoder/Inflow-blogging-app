**InkFlow — Modern Full-Stack Blogging Platform

InkFlow is a full-stack blogging application built with React.js, Node.js, TypeScript, and PostgreSQL that allows users to create, publish, and manage blogs with secure authentication and a clean responsive user experience.

***Features***
Secure JWT-based Authentication
Create, Edit & Delete Blogs
Responsive Modern UI with Tailwind CSS
Global State Management using Recoil
PostgreSQL Database Integration
RESTful API Architecture
Serverless Backend Deployment using Cloudflare Workers
Fast and Scalable Performance


***Tech Stack***

*Frontend*
•React.js
•Typescript
•Recoil
•Tailwind CSS
•Axios
•React Router DOM
*Backend*
•Node.js
•Hono
•Prisma ORM
•PostgreSQL
•JWT Authentication
**Deployment**
•Cloudflare Workers - for Backened
•Netlify - for Frontend
